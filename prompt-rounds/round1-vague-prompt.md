# Round 1: Vague Prompt Example

---

## Prompt

> Create a user authentication system with user login and user registration.

---

## Quick Analysis

### What the AI Would Assume

* A default tech stack (for example, Node.js, Python, or Firebase)
* An authentication method (sessions or tokens)
* Basic password validation rules
* A simple database structure

### Critical Details Missing

* **Tech stack and architecture**
* **Security requirements** (password hashing, rate limiting, token expiry)
* **API endpoints** and request/response format
* **Error handling** behavior and messages
* **Data schema** and validation rules
* **Success criteria** (performance, test coverage, production readiness)

---

## Confidence Level

> **3/10** - Good for brainstorming, not reliable for implementation.
